### AI แนะนำอะไร

เขียนโค้ดให้ทั้งชุด แยกเป็น 8 ไฟล์ตามขั้นของไปป์ไลน์ (`config` → `fetch_snapshots` →
`columns` → `clean` → `dimensions` → `load` → `run_dims` → `verify_dims`)
ข้อเสนอเชิงออกแบบที่ไม่ได้อยู่ในเอกสารออกแบบเดิมมีสี่ข้อ

1. ให้ทุก dimension มีแถว `key = -1` สำหรับ "ไม่ทราบ" ไม่ใช่เฉพาะ `Dim_Date`
2. ให้ `Dim_Chain` แยกแถว "ไม่สังกัดเครือ" (`chain_key = 0`) ออกจาก "ไม่ทราบ" (`-1`)
   เพราะงวดปี 2562 ไม่มีคอลัมน์เครือเลย จึง *ไม่รู้* ต่างจากงวดปี 2569 ที่คอลัมน์ว่าง
   ซึ่งแปลว่า *รู้ว่าไม่สังกัด*
3. ใช้ `Processing Date` ในไฟล์เป็นแกนเวลาของ SCD2 ไม่ใช่วันที่ของ ZIP บนเซิร์ฟเวอร์
4. ตอนเทียบ SCD2 ให้เทียบเฉพาะคอลัมน์ที่รู้ค่าทั้งสองฝั่ง

```sql
INSERT ... facility_key = 88888888   -->  Violates foreign key constraint
UPDATE ... overall_rating = 9        -->  CHECK constraint failed
```

| ตรวจอะไร | วิธี | ผล |
|---|---|---|
| ข้อบังคับจับของจริงได้ไหม | รันครั้งแรกกับข้อมูลจริง | **จับได้ทันที** — `dim_geography_zip_width` ปฏิเสธแถว Unknown (เป็นบั๊กของสคีมาเอง แก้แล้ว) |
| FK บังคับใช้จริง | INSERT `facility_key` ที่ไม่มีอยู่ | **ถูกปฏิเสธ** |

| `drop_stale_facts` ทำงานจริง | รัน `run_dims.py` แล้ว `SHOW TABLES` | เหลือ 6 dimension **ไม่มีตาราง Fact** |
