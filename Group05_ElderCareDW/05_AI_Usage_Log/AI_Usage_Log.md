**ด้านโครงสร้างโปรเจกต์**

- ไฟล์ `.gitkeep` ที่ราก repo เป็นสคริปต์ shell ที่หลุดมา มี path เครื่องคนอื่นฝังอยู่ (`/home/panguin/...`) ควรลบ

- โฟลเดอร์ `01_`–`05_` ตามที่โจทย์กำหนดยังไม่ถูกสร้าง ทั้งที่ `.gitignore` อ้างถึงอยู่แล้ว
- `05_AI_Usage_Log` ไม่ปรากฏในรายการ "สิ่งที่ต้องทำก่อนเริ่มพัฒนา" ของเอกสารออกแบบเลย ทั้งที่เป็นสิ่งที่ต้องส่ง และเป็นสิ่งเดียวที่เขียนย้อนหลังไม่ได้
- ลิงก์ในเอกสารออกแบบชี้ไปที่ `group project/69-1-...pdf` และ `PROGRESS.md` ซึ่งไม่มีอยู่จริง

**ด้านการออกแบบคลังข้อมูล** (ยังเป็นข้อสังเกต ยังไม่พิสูจน์)

1. การเก็บตัวคูณ VBP เป็น "แอตทริบิวต์ระดับปี" ใน `Fact_Facility_Monthly` ขัดกับกล่องส้มของตัวเอง
   ที่เตือนเรื่องการนับซ้ำข้าม grain — ควรแยกเป็น fact ที่สาม (facility × ปีงบประมาณ)
2. M2 `resident_days` นิยาม "จำนวนวันในงวด" ไม่ชัด — เดือน / ช่วงห่างระหว่าง snapshot ที่เลือกมา (~90 วัน) /
   ไตรมาสรายงานของ CMS ให้ค่าต่างกันถึง 3 เท่า และ M2 เป็นตัวถ่วงน้ำหนักของ M1/M3/M4 กับตัวหารของ M9
3. `pop_65plus` อยู่ใน `Dim_Geography` ซึ่งเป็น SCD1 ที่ grain ระดับ ZIP — ค่าประชากรรัฐจะซ้ำหลายพันแถว
   (SUM แล้วพุ่ง) และเป็นค่าคงที่ปีเดียวทั้งที่ BQ1 ต้องดูแนวโน้ม 2562–2569

**กลุ่มตัดสินสี่ข้อ (AI ถามก่อนเริ่มเขียน)**

### AI แนะนำอะไร

**ข้อสรุปเดิมของกลุ่มที่ว่า "CMS เผยแพร่เฉพาะไฟล์ปัจจุบัน ต้องพึ่ง Internet Archive" ไม่จริง**

### ตรวจสอบความถูกต้องอย่างไร

**1. บทเรียนสำคัญ — การค้นรอบแรกรายงานผลไม่ครบ**
`grep` ในเชลล์นี้ถูกครอบด้วยฟังก์ชันที่เปิด `--ignore-files` (เคารพ `.gitignore`)
รอบแรกจึงตอบว่า `.venv` ไม่มี path เดิมเลย ทั้งที่จริงมี **ต้องเรียก `/usr/bin/grep`
ตรง ๆ ถึงเห็นของจริง**

```bash
grep -rl "Group01_ElderCareDW" Group05_ElderCareDW/.venv | wc -l          # ตอบ 0
/usr/bin/grep -rl "Group01_ElderCareDW" Group05_ElderCareDW/.venv | wc -l # ตอบ 1557
```

**ผลการตรวจ:** ต่างกัน 0 กับ 1,557 ไฟล์ · การค้นทั้งหมดหลังจากนี้ใช้ `/usr/bin/grep`

**2. พิสูจน์ว่า venv ยังใช้งานได้หลังเปลี่ยนชื่อโฟลเดอร์**

```bash
head -1 Group05_ElderCareDW/.venv/bin/streamlit
Group05_ElderCareDW/.venv/bin/python -c "import duckdb,pandas;print('venv ok')"
```

**ผลการตรวจ:** shebang ชี้ไป `Group05_...` แล้ว · import ผ่าน · ที่เหลืออีก 1,538 ไฟล์
เป็น `.pyc` ซึ่ง Python สร้างใหม่เองและไม่กระทบการรัน

**3. เปิด PDF ที่ build ใหม่มาอ่านข้อความบนหน้าปกจริง ไม่ใช่เชื่อว่า build ผ่านแล้วถูก**

### บทเรียนที่ควรพูดในวิดีโอ

**"หาไม่เจอ" กับ "ไม่มี" ไม่ใช่เรื่องเดียวกัน** ถ้าเชื่อผลค้นรอบแรก จะสรุปว่า venv
